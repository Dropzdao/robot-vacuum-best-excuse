Entry for the [make.fun](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) competition **The Robot Vacuum's Best Excuse**: write the funniest one-line excuse a robot vacuum gives for missing a spot.

`main.py` writes one line (122 characters) to `/output/entry.txt`:

> My lidar mapped that corner as a cliff, so I filed it under 'do not enter' and went back to my dock for emotional support.

Run it with `python3 main.py`.
